# HAIZIM TOOLS

### Deskripsi

Kumpulan tools berbasis web sederhana yang dibuat untuk membantu berbagai tugas pengembangan dan produktivitas sehari-hari. Proyek ini menggunakan teknologi web modern seperti Alpine.js dan Tailwind CSS untuk antarmuka yang responsif dan ringan.

### List Tool

***html-formatter.html***

Alat untuk memformat dan meminifikasi kode HTML.
*   **Fitur:** Format HTML (Beautify), Minify HTML, Copy to Clipboard, Syntax Highlighting.

***html-viewer.html***

Penampil HTML real-time dengan berbagai mode tampilan.
*   **Fitur:** Editor Source Code, Live Preview, Split View, Mobile View, Fullscreen View.

***json-analyzer.html***

Analisis data JSON menggunakan kekuatan AI via OpenRouter.
*   **Fitur:** JSON Editor, Upload File JSON, Chat dengan AI untuk analisis data, Dukungan Markdown.

***json-formatter.html***

Formatter dan validator JSON yang mudah digunakan.
*   **Fitur:** Format JSON, Syntax Highlighting, Validasi Error, Copy Result, Dark/Light Mode.

***json-map.html***

Visualisasi struktur data JSON dalam bentuk diagram pohon (Tree View).
*   **Fitur:** Visualisasi Interaktif, Zoom In/Out, Collapsible Nodes, Live Edit, Dark/Light Mode.

***openrouter-client.html***

Klien chat antarmuka web untuk berinteraksi dengan berbagai model AI melalui OpenRouter API.
*   **Fitur:** Multi-chat History, Pilihan Model AI, Custom System Prompt, Streaming Response, Markdown Rendering.

***print-termal-tes.html***

Generator halaman tes untuk printer thermal (struk).
*   **Fitur:** Dukungan lebar 58mm & 80mm, Pengaturan Margin & Font Size, Pola Tes Alignment & Density.

***print-tes.html***

Generator halaman tes cetak standar untuk printer A4.
*   **Fitur:** Tes Warna CMYK/RGB, Tes Ketajaman Teks (Text Sharpness), Grid Alignment, Info Tanggal Cetak.

***spreadsheet-analyzer.html***

Alat analisis file spreadsheet (.xlsx, .csv) berbantuan AI.
*   **Fitur:** Import File Excel/CSV, Tampilan Data Tabel, Chat dengan AI (data terlampir otomatis), AI Model Selector.

***table-converter.html***

Editor tabel visual dengan kemampuan ekspor ke berbagai format kode.
*   **Fitur:** Live Table Editor, Import dari Excel/Sheets, Tambah/Hapus Baris & Kolom, Ekspor ke Markdown/JSON/HTML/XML.

***todo-list.html***

Aplikasi manajemen tugas (Todo List) dengan pengelompokan.
*   **Fitur:** Pengelompokan Tugas (Groups), Drag & Drop (Reorder), Progress Tracking, Dark Mode, Penyimpanan Lokal (LocalStorage).
